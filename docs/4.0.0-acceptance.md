# BoltWrt 4.0.0 P0 验收清单

本清单按用户原 P0-1～P0-6 编号记录完成条件和证据。截至 2026-10-22 编写时，**六项 P0 均未整体关闭**。已完成上游源码替换、必要定制迁回、配置准备及部分隔离测试；尚未完成任一平台的完整固件编译，也没有实际固件 manifest／镜像验收。用户尚未通知运行环境可用，未开展设备启动、真实升级或网络验收。

这是一份状态快照。`e1af37c` 下两平台 prepare＋defconfig 和顶层 `make download` 已通过，但后者未覆盖随后编译补取的 host 源码，不能当作全部构建输入已齐备。两平台的 host 工具、交叉工具链及 Go 1.26.9 host 编译现均退出 0。CMCC 首轮因 Go 1.4 bootstrap 不支持 linux/arm64 宿主而退出 2；后续两卷分别使用容器固定 Go 1.26.8，从锁定源码构建并安装 Go 1.26.9。两平台现均已生成各自架构的 Linux 6.12.112 内核 ELF。RAX 的 Python 3.13.15 已源码安装并通过实际解释器检查，完整构建正编译 Rust／LLVM 及其他包；x86 完整构建尚未启动。内核 ELF 不是完整固件或启动证据。

两平台当前执行源码均为 `883b0d4e`，已包含独立审查及 native UCI 7 项通过的 Aliyun 修复 `30b596e6`／`b63fe068`。同步仅在各自无 make 时精确替换已审查的 8 项差异并保留原内容；随后两平台重复准备的配置及完整源记录保持相同。后续结果须补入对应行，不能从“代码已修复”“配置选择保留”推定编译或运行通过。最终依赖以 [config/source-lock.json](../config/source-lock.json) 为权威；同时保存实际主仓 commit、锁／配置 SHA256 和有效命令行覆盖，避免混用不同输入。
