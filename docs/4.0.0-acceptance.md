# BoltWrt 4.0.0 P0 验收清单

本清单按用户原 P0-1～P0-6 编号记录完成条件和证据。截至 2026-10-22 编写时，**六项 P0 均未整体关闭**。已完成上游源码替换、必要定制迁回、配置准备及部分隔离测试；尚未完成任一平台的完整固件编译，也没有实际固件 manifest／镜像验收。用户尚未通知运行环境可用，未开展设备启动、真实升级或网络验收。

这是一份状态快照。本轮 Linux 构建的源码快照为 `e1af37c`，其两平台 prepare＋defconfig 和严格全量下载均已通过；CMCC 的 host 工具及交叉工具链已完成，正在实际固件编译，x86 正在构建 host 工具。此后 Aliyun 迁移修复 `30b596e6`／`b63fe068` 已通过独立审查及 7 项 native UCI 测试，但尚未同步到这两份运行中的构建源码；最终产物须包含该修复并重新构建、验证。后续结果须补入对应行，不能从“代码已修复”“配置选择保留”推定编译或运行通过。最终固定依赖以 [config/source-lock.json](../config/source-lock.json) 为权威；同时保存实际执行的主仓 commit、锁文件 SHA256 和准备记录，避免混用不同输入的证据。

## 状态和证据规则

| 状态 | 含义 |
| --- | --- |
| 通过 | 已在该行注明的输入和证据层实际满足条件，仅覆盖该层。 |
| 失败 | 已真实执行且未满足条件；修复提交本身不能把失败改为通过。 |
| 受阻 | 缺少已明确的前置条件、产物或用户运行环境，尚不能完成该项验收。 |
| 未执行 | 尚无该项执行记录，不声称成功或失败。 |
| 进行中 | 已实际开始，尚无完整成功或失败结果。 |

源码审查、语法检查、合成数据测试、真实 UCI/JSHN 配置语义、实际包管理操作、交叉编译、镜像解析及设备运行分别记录。每项 P0 必须达到自身全部完成条件才能关闭；未关闭的启动、硬件或升级验证继续留在 P0。
