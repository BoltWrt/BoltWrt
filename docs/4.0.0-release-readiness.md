## 旧版功能与包差异

x86两份实际manifest分别为323包与333包；同名308包、旧独有15包、新独有25包。包数增加不能证明功能未减少；同名也不能保证全部配置语义相同。

| 旧版项 | 新版处理与结论 |
| --- | --- |
| `opkg` | 改为`apk-mbedtls`；旧IPK、用户自行安装包及opkg脚本不能直接沿用。 |
| `ddns-scripts_aliyun` | 改为官方`ddns-scripts-aliyun`；已有精确域名迁移，但不是任意用户配置或真实更新链路兼容保证。 |
| `luci`、`luci-light`、`luci-ssl-openssl`、`uhttpd`、`uhttpd-mod-ubus` | 统一使用已有nginx/uwsgi/LuCI栈；不能承诺依赖uhttpd的自定义配置继续可用。 |
| `luci-theme-bootstrap` | 明确不在新manifest中，备用主题减少；旧用户选用该主题时不能只靠保留主题配置保证页面正常。用户已明确接受删除；旧配置若仍指定Bootstrap需切换到已保留的Argon，不能只保留不存在的主题路径。 |
| `zabbix-agentd-openssl` | 改为实际包`zabbix-agentd-basic`，仍依赖OpenSSL；同配置／启动脚本，旧未选LDAP/NetSNMP。 |
| `libblobmsg-json20240329`、`libjson-script20240329`、`libubox20240329`、`libubus20250102` | 对应新日期ABI包；不能外推用户自带旧ABI二进制兼容。 |
| `liblua5.3-5.3` | 改为`liblua5.4-5.4`，属于运行时迁移。 |
| `libustream-openssl20201210` | 改为`libustream-mbedtls20201210`；不能用nginx仍选OpenSSL来推定所有客户端TLS后端不变。 |

这15个旧独有名称全部列于上表。25个新独有名称为：`apk-mbedtls`、`boltwrt-defaults`、`ddns-scripts-aliyun`、`kmod-crypto-aead`、`kmod-crypto-chacha20poly1305`、`kmod-crypto-kpp`、`kmod-crypto-manager`、`kmod-crypto-null`、`kmod-netlink-diag`、`kmod-ovpn-backports`、`libblobmsg-json20260213`、`libjson-script20260213`、`liblua5.4-5.4`、`liblz4-1`、`liblzo2`、`libnl-core200`、`libnl-genl200`、`libubox20260213`、`libubus20251202`、`libustream-mbedtls20201210`、`openvpn-openssl`、`ucode-mod-log`、`ucode-mod-uloop`、`wget-ssl`、`zabbix-agentd-basic`。

旧实际x86清单只有`luci-app-openvpn`，没有OpenVPN后端；新版补齐`openvpn-openssl 2.7.7-r1`。不能将其叙述为旧版内置后端升级已经无损。OpenVPN static-key默认拒绝、发送压缩、未声明topology和DCO差异，以及Aliyun域名／pending delta边界，均保留在[升级边界](4.0.0-upgrade-validation.md)和[平台说明](4.0.0-platform.md)。不恢复用户已取消的对端与流量测试。

RAX旧官方发布归档现已从[v3.1.2](https://github.com/BoltWrt/BoltWrt/releases/tag/v3.1.2)取得：185,408,126字节，SHA256 `f6ce85ef5d95df81b98743e1a2c05caa85c1f5e2e5ae2d901b19e3e02a341059`与GitHub API公布digest完全相等。归档内`./boltwrt-mediatek-filogic-cmcc_rax3000m.manifest`为343包，SHA256 `e3348809df5e8e7f9c4422f81232dfc6b051795c1de0f3704ac8ee20207de5cb`。与前次真实350包产物比较，旧独有17、新独有24、同名版本改变283、同名版本不变43；不再以旧配置冒充实际清单。

- **iwinfo命令未删除，纠正此前按独立包名推断的错误。** 它用于查看无线接口、信号、扫描结果、连接客户端和信道等。旧版是66,062字节ELF；新版生产rootfs和正常wifi-scripts APK均含同字节的`/usr/bin/iwinfo`，改为6,095字节ucode CLI，SHA256 `c279f6cc7000ee1cb7609a0a60f77a63500a85d6be1b1fe32afa333fe176ff1c`。上游WIFI_SCRIPTS_UCODE模式由wifi-scripts提供实现，不再依赖旧独立C CLI；无需恢复重复包，不承诺旧输出格式逐字节一致。
- **Aquantia是AQ/AQR系列有线以太网PHY驱动，不是无线或通用PHY框架。** 旧实际rootfs含36,200字节`aquantia.ko`，来自旧Filogic平台全局默认。两版RAX设备树使用MT7981集成PHY、MT7531，新版增加AN8855；没有AQ/AQR硬件依赖。新平台不再全局默认携带此驱动，所需设备逐个选择。因此RAX保持不选，不为旧包名一致恢复冗余驱动。CPU至交换芯片的2500base-x链路不等于使用Aquantia铜缆PHY。
- **PHY框架保留。** 两版Filogic均内建`CONFIG_PHYLIB=y`；旧kmod-libphy的实际文件清单只有自动加载文件，没有独立libphy.ko。不能把空壳包名消失当作框架删除。

源代码、官方Linux驱动匹配ID、实际旧／新rootfs和APK证明、17／24项完整分类与版本表位于`E`旁的`.evidence/4.0.0/release-update-20261029/rax-parity/`。Bootstrap接受删除；iwinfo实现替换、Aquantia与libphy已完成分类，不再作为功能删减待裁决项。未知用户自带ABI二进制、旧主题配置及被取消链路的兼容边界仍不外推。

## 建议的交付顺序

1. Bootstrap、iwinfo及PHY包差异已完成裁决；上述已入镜像组件的安全更新或必要补丁已提交并独审，继续完成更新后的实际构建和验收；将代码、构建与运行分别记录。不要为追最新版而擅自更换OpenWrt正式基线或整个工具链。
2. 对实际修改执行对应下载认证、配置／生成器回归及双平台重构建；按受影响范围复用本机验收，不恢复已取消的板级、对端或流量测试。旧产物不能代替修改后的新产物。
3. 得到明确授权后，先推送Packages依赖提交，再推主仓候选分支并手动运行双平台CI。当前工作流普通develop推送不会构建，`workflow_dispatch`才会手动构建；`v*.*.*`标签推送会进入发布job，不能用打标签替代候选验证。
4. 核对候选产物后再单独决定正式发布／部署。发布资产完善仍为原P1范围，本记录不擅自实施；也不把本次问题搬入P1来宣布可以上线。
