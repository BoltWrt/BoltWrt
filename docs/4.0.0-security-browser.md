## 真实浏览器进度

测试在单独的x86 UEFI完整镜像克隆盘上运行，初始固件SHA256 `0e26da8ae497b786dcfd22df4b2436ac7c480d5a8fb7451f9b137370971b7fc0`。用户本人在Chrome接受本机测试VM的自签名证书。原Chrome盘、升级盘、签名密钥与其他任务资源均保留。

- SmartDNS：端口70000校验拒绝；新增回环上游、编辑常规／高级设置、保存并应用、运行状态和页面重载持久化已实际验证。客体procd和生成配置确认端口6053绑定lo、上游127.0.0.1:9；网络、DHCP、APK状态不变。已通过UI停用测试服务。没有进行DNS查询、WAN或服务对端验收。
- PassWall2：端口越界拒绝、有效端口1087、直连UseIPv4／远程UseIPv6保存应用已验证。主开关保持关闭，节点自动检测关闭。新增节点和FakeDNS错误有真实浏览器／客体证据，修复后新增、编辑、保存、重载、删除及组件页仍待验证；契约模型不代替真实浏览器。
- 控制错误分别保留：早期CLI观察路径写错、过长串口行截断、host Xcode依赖及容器/tmp不可执行均未改写成成功。更正后只补必要观察。Dashboard的可选wireless探测捕获到缺少配置并隐藏该widget，与PassWall真实空引用分开记录。
