# BoltWrt 4.0.0 发布与验收

## 发布构建

2026-11-08（北京时间）发布的 `v4.0.0` 指向固件提交 `143668ff972577f3bd3ec16f70bdda34aa35074b`，自定义 feed 锁定为 `45ad2e027ad925eb084231421bb6a7576aa099e3`。GitHub Actions 双目标构建和静态检查通过，发布了 x86-64 与 RAX3000M／Me 两个归档。下载文件及摘要以 GitHub Release 为准。 [v4.0.0 发布页](https://github.com/BoltWrt/BoltWrt/releases/tag/v4.0.0) · [GitHub Actions 构建](https://github.com/BoltWrt/BoltWrt/actions/runs/42376595213)

## 发布前运行验收

2026-11-06 的本地验收使用固件提交 `7d1c6614571c1a7960a406344c98826befef677a` 和 Packages 提交 `fbb14623f8cc66f4dcc7d60d2f142c254919d7de`。发布锁中的 Packages 合并提交与该 feed 输入的 Git 树相同。下表的运行结果绑定本地构建的镜像和配置。 [原始记录及摘要](https://github.com/BoltWrt/BoltWrt/blob/v4.0.0/docs/4.0.0-hysteria-validation.md)

| 验收项 | 实际覆盖 |
| --- | --- |
| x86-64 构建与产物 | 生产 manifest 334 包，仓库 340 个 APK。用签名索引核对 manifest 对应的 334 包，并在认证 APK、rootfs 和四种整盘镜像中比对选定载荷。BIOS、UEFI 各自的 IMG 与 VMDK 解码后作静态对比。 |
| x86-64 首次启动与升级 | UEFI IMG 新装及客体重启。用 v3.1.2 BIOS IMG 在 IDE／e1000 虚拟机执行标准保留配置升级，实际写入分区及引导、自动启动，并再次重启。受控配置、脚本、实际 HTTPS 证书和独立 HAProxy 启用意图保留，APK 数据库可用，旧 opkg 数据库及二进制未恢复。 |
| x86-64 LuCI | 在已实际升级的旧 UI 克隆中使用 Chrome 验证节点增删改和持久化，并通过生产 LuCI／ubus 路径生成配置、让独立 Hysteria2 和 Sing-box 分别加载。检查了 FakeDNS 控件依赖、组件版本检测和 SmartDNS 保存／恢复。FakeDNS 只操作表单，组件页只检测版本。 |
| RAX 构建与产物 | 生产 manifest 351 包，核对签名索引、认证 APK、rootfs、生产 FIT 及选定关键载荷。 |
| RAX ARM 用户态 | 从同次生产 FIT 取出的 ARM/musl 用户态通过 36 条有界命令，覆盖 APK 查询、独立 Hysteria2 版本、ChinaDNS 依赖版本、Lua 模块、配置解析和规则数据处理。 |

本地验收范围限于上述软件用例。RAX 实机启动与刷写（含 NAND／eMMC、DDR、交换芯片和坏块）、WAN、服务对端、真实流量及物理无线未执行。x86 的其他磁盘组合、自定义分区或更早版本直接升级未在该代次验证。
